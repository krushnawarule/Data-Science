# Data-Science
This repository contains my Data Science assignments including data preprocessing, normalization, standardization and exploratory data analysis using Python.

## Simple data filtering and cleaning

A lightweight example script is available in `simple_data_filtering_cleaning.py`.

It demonstrates how to:
- normalize column names,
- remove duplicates,
- fill missing numeric and categorical values,
- and filter students using score and attendance conditions.

Run it with:

```bash
python simple_data_filtering_cleaning.py
```
